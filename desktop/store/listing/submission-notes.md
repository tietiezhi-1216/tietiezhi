# Microsoft Store 审核说明

## 测试说明

应用无需注册 Tietiezhi 账号即可启动和查看界面。AI 对话功能不内置第三方模型凭据；如需完整测试，请在设置中添加审核人员自有的 OpenAI API 兼容服务地址、API Key 和模型名称。

应用不会申请管理员权限，也不会提升进程权限。

## 语音听写与麦克风

应用声明麦克风能力，用于用户主动触发的语音听写。应用不会在后台自动录音；每次录音均由用户点击麦克风按钮或按下全局快捷键开始，并由用户结束，单次录音最长五分钟。

测试路径：

1. 在「设置 → 模型供应商」登录 Tietiezhi Gateway，或添加审核人员自己的 OpenAI API 兼容服务。
2. 在「设置 → 语音听写 → 模型」选择语音识别模型和文本润色模型。
3. 点击聊天输入框旁的麦克风按钮，或使用设置页显示的全局快捷键。
4. 首次使用时允许麦克风权限，说话后结束录音。
5. 应用会显示识别与润色进度，并将结果输入当前文本框；没有可输入位置时显示可复制结果。

## `runFullTrust` 使用理由

Tietiezhi 是基于 Tauri 2 的本地优先桌面应用，使用 `mediumIL` 运行。智能体工作流需要在用户明确选择或由应用创建的工作区内访问文件、启动本地子进程，以及连接用户配置的 MCP stdio 服务。API Key 使用操作系统安全凭据存储。涉及敏感操作的工具受应用内权限模式和用户确认控制。

## 数据与网络

应用只会将用户输入及必要上下文发送到用户自行配置的模型服务或 MCP 服务。语音听写时，录音发送到用户选择的语音识别服务；启用润色时，识别文字发送到用户选择的润色模型。应用不出售个人数据，也不包含广告或默认遥测。完整说明见隐私政策。
